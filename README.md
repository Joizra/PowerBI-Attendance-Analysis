# PowerBI_Education
#PowerBI#dashboard#history

## Summary
The Created an interactive Power BI dashboard to analyze the attendance rates across various schools within a jurisdiction.


## Methods
PowerBI 2024 version 2 was used to analyze the data.

The data analyst designed a report that displays the following:

* Data Segmentation filters
* KPI: Atendance rate, Attendance, and Non-Atendance.
* Ranking of non-attencae reasons



## Results
The overall attendance rate is 0.72. The closer this value is to 1, the better, as it indicates a lower non-attendance rate compared to the attendance rate. The overall attendance is 2.6 times the overall non-attendance.
The top four non-attendance reasons are as follow:
* Un-notified absence, 
* Sanctioned, 
* Notified as sick, 
* Unacceptable reasons.
